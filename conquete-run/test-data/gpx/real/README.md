# Vraies traces (non-régression)

Déposez ici des GPX exportés de vraies courses (app ou montre). `npm test` vérifie
qu'ils sont validés par la chaîne serveur, sans véhicule détecté, et que la distance
filtrée reste proche de la distance brute lissée. Anonymisez-les d'abord (retirez
début et fin près du domicile).
